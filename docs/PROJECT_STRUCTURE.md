# Карта структуры проекта

Документ помогает быстро найти собственный код, контент приложения и файлы зависимостей. Основное правило: новый контент приложения размещается в `Assets/App`, а Unity-пакеты и ресурсы шаблонов остаются в своих каталогах.

## Каталоги верхнего уровня

```text
AR_Unity/
├── Assets/
│   ├── App/                         # Собственные сцены, префабы, ресурсы и скрипты
│   │   ├── Content/                 # AR-карточки, UI, иконки и фирменная графика
│   │   ├── DatabaseTools/Editor/    # Окно экспорта PostgreSQL → SQLite
│   │   ├── Scenes/                  # Вход, меню, выбор инвентаризации, AR-сцена
│   │   └── Scripts/                 # Логика приложения по областям
│   ├── Plugins/Android/             # QR-модуль, Android Manifest и Gradle-настройки
│   ├── StreamingAssets/             # Файлы, копируемые в сборку без импорта
│   │   └── InventoryDatabase/       # Начальная SQLite-база
│   ├── Settings/                    # URP и настройки рендеринга
│   ├── MobileARTemplateAssets/      # Зависимости используемого AR-шаблона
│   ├── Samples/                     # Используемые примеры XR Interaction Toolkit
│   ├── Packages/                    # .NET-библиотеки, подключённые NuGet for Unity
│   └── TextMesh Pro/, XR/, XRI/     # Ресурсы и настройки пакетов Unity
├── Backend/
│   ├── Database/                    # Чистая схема, разовое обновление текущей БД и демо-данные
│   ├── Data/                        # SQL-запросы и репозитории PostgreSQL
│   ├── Endpoints/                   # REST API: вход, QR, коробки, назначения, отчёты
│   ├── Services/                    # Синхронизация, медиа и формирование Excel
│   ├── admin.html, main.js, style.css # Административная веб-панель
│   └── Program.cs                   # Запуск сервера и регистрация REST-маршрутов
├── Packages/                        # UPM-манифест и lock-файл Unity
├── ProjectSettings/                 # Настройки проекта и платформ
├── docs/                            # Документация и изображения для неё
└── AR_Unity.slnx                    # IDE-решение
```

## Где лежит нужный файл

| Задача | Каталог |
|---|---|
| Изменить вход, меню или AR-сцену | `Assets/App/Scenes` |
| Изменить внешний вид AR-карточки | `Assets/App/Content/Cards` |
| Изменить экран отчёта или голосовой помощи | `Assets/App/Content/UI/Prefabs` |
| Добавить иконку или фирменную графику | `Assets/App/Content/UI` или `Assets/App/Content/Branding` |
| Изменить поведение карточки | `Assets/App/Scripts/AR/Cards` |
| Изменить QR или голос | `Assets/App/Scripts/QR` или `Assets/App/Scripts/Voice` |
| Изменить подключение к API | `Assets/App/Scripts/Network` |
| Изменить офлайн-хранилище или синхронизацию | `Assets/App/Scripts/Local` |
| Изменить схему базы сервера | `Backend/Database` |
| Изменить версию Unity-пакета | `Packages/manifest.json` через Package Manager |

## Код приложения

В `Assets/App/Scripts` логика сгруппирована по назначению:

- `Managers` — вход, состояние пользователя, экран главного меню и данные между сценами.
- `Local` — SQLite, локальные модели, результаты действий и очередь синхронизации.
- `Network` — клиент API и модели ответов сервера.
- `QR` — сканирование и переходы после чтения кода.
- `Voice` — распознавание речи, контекстные команды и подсказки.
- `AR` — выбор режима карточки, спавнер, манипуляции и маркер размещённого объекта.
- `AR/Cards` — калькулятор, изображения содержимого коробки, чек-лист и отчёт.
- Скрипты в корне `Scripts` — раскладка UI входа и главного меню.

Сцены и префабы задают постоянную визуальную иерархию. Скрипты подключают действия и обновляют данные, зависящие от выбранного QR или ответа API. Для чек-листа строки клонируются из оформленного `ItemTemplate` префаба.

## Системные и сторонние ресурсы

- `Packages/` — UPM-пакеты Unity и закреплённые версии зависимостей.
- `Assets/Packages/` — .NET DLL-библиотеки, которыми управляет NuGet for Unity; это отдельная система пакетов.
- `Assets/Plugins/Android/` — Android-специфичные интеграции и настройки сборки.
- `Assets/MobileARTemplateAssets/` и `Assets/Samples/` — ресурсы Unity AR-шаблона и XR Interaction Toolkit. Не удаляй их без проверки GUID-ссылок из сцен и префабов.
- `Assets/Settings/` — активные настройки URP.
- `Assets/StreamingAssets/InventoryDatabase/inventory.db` — экспортированный стартовый справочник. Рабочая база приложения находится в постоянном хранилище устройства.
- `Library/`, `Temp/`, `Logs/`, `UserSettings/`, `obj/` и `bin/` — генерируемые рабочие каталоги; их можно восстановить, открыв проект или пересобрав сервер. APK и резервные копии не удаляй как временные файлы.

## Как безопасно менять ресурсы

1. Новые элементы приложения создавай внутри `Assets/App`.
2. Постоянную разметку собирай в сцене или префабе и настраивай через Inspector.
3. Для перемещения или переименования ассета используй Unity Editor. Если работаешь с файлами напрямую, переноси вместе с `.meta`.
4. Перед удалением проверь ссылки на ассет в сценах, префабах, настройках и коде. Удаляй ресурс только после проверки его GUID и строковых загрузок вроде `Resources.Load`.
5. Для новой PostgreSQL-базы выполняй `Backend/Database/schema.sql`; существующую базу один раз обновляй `Backend/Database/update_database_to_boxes.sql` после резервного копирования.

Манифест и lock-файл `Packages/` нужны для восстановления версий Unity-зависимостей на другой машине. Папки `Library` и `Temp` переносить для открытия проекта не нужно: Unity пересоберёт их по манифесту и исходным ассетам.
