# Материалы приложения

Это основное место для визуальных материалов, созданных специально для приложения. Новые собственные карточки, логотипы и иконки складывай сюда, а ресурсы Unity и AR-шаблона оставляй в их исходных папках.

## Карточки дополненной реальности

В `Cards` находятся:

- `WebCard.prefab` — карточка WebView;
- `ProductInfoCard.prefab` — карточка с информацией о продукции;
- `CalculatorCard.prefab` — калькулятор.

Сейчас в `ObjectSpawner` сцены `SampleScene` оставлены только эти три карточки. Каждая использует одинаковую основу AR-взаимодействия из шаблона: перетаскивание, перемещение и изменение размера.

Чтобы добавить ещё одну карточку:

1. В Unity продублируй подходящий Prefab из `Cards` и дай ему понятное имя.
2. Измени его визуальные элементы и текст в Prefab Mode.
3. Добавь её в `Object Prefabs` компонента `ObjectSpawner` сцены `SampleScene`.
4. В меню `SampleScene → UI → Content` продублируй одну из трёх кнопок AR-карточек. В её обработчике назначь новый Prefab в поле **Card Prefab**.
5. Кнопка выбирает карточку в явно заданном списке спавнера; карточка, не добавленная в этот список, покажет понятную ошибку вместо скрытого изменения списка во время запуска.

Для уже настроенных специальных кнопок оставлены свои обработчики: Web-кнопка использует `WebButtonHook`, а карточка продукции — `ImageButtonHook`. В Inspector у них также назначается префаб карточки, без индекса. Калькулятор и новые стандартные AR-карточки используют общий `ARCardButtonHook`.

Поведение карточек находится отдельно от Prefab:

- калькулятор — `Assets/App/Scripts/AR/Calculator`;
- карточка продукции — `Assets/App/Scripts/AR/Cards`;
- Web-карточка — `Assets/App/Scripts/AR/Web`.

### Как устроен интерфейс карточки

Открой Prefab двойным щелчком и раскрой `Canvas → Panel`. Все кнопки и подписи теперь сохранены как обычные UI-объекты и доступны для правки в Inspector:

- `CalculatorCard`: `Display`, `Grid` с 16 кнопками и `Close`.
- `ProductInfoCard`: `Title`, `Sheet` и `Row` с кнопками листов и закрытия.
- `WebCard`: `Title`, `Preview` (внутри `Placeholder`, `RawImage`, `Status`) и `Buttons` (`RefreshBtn`, `OpenBtn`, `CloseBtn`).

Менять внешний вид и расположение можно прямо в этой иерархии. Скрипты карточек подключают действия к готовым кнопкам при запуске. Не удаляй и не переименовывай объекты с действиями, если не меняешь соответствующий контроллер.

## Кнопки меню

В `StartScene` кнопки главного меню находятся в `Canvas → Menu Buttons`, а логотип, заголовок и справка — в `Canvas → Header`. Дублируй существующую кнопку, чтобы сохранить общий стиль. Для нового действия потребуется подключить его к менеджеру меню; для кнопки спавна AR-карточки отдельные изменения в `MainMenuManager` не нужны — используй `ARCardButtonHook`.

## Остальные материалы

- `Branding` — логотипы и знак Норникеля.
- `UI/Icons` — иконки интерфейса: `Calculator.png`, `icon_info.png` и `icon_view.png`. Новые `icon_info` и `icon_view` пока лежат в библиотеке приложения; в сценах они ещё не подключены к компонентам Image/Button.

Unity использует `.meta`-файл для связей с ресурсом. Перемещай или переименовывай ассет вместе с его `.meta`.
