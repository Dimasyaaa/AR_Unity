Они опубликованы на Wikimedia Commons под лицензией CC0 1.0.

- `CabinetReference.jpg` — лист 1: [Museum flat file storage cabinet](https://commons.wikimedia.org/wiki/File:Museum_flat_file_storage_cabinet.jpg)
- `CabinetReference_2.jpg` — лист 2: [Museum flat file storage cabinet with art work](https://commons.wikimedia.org/wiki/File:Museum_flat_file_storage_cabinet_with_art_work.jpg)
