# Скрипты приложения

Скрипты обрабатывают события и связывают пользовательский интерфейс с данными приложения. Постоянные элементы интерфейса создаются в сценах и префабах; скрипт не должен заново собирать уже оформленную кнопку или панель во время запуска.

## Папки

| Каталог | Ответственность |
|---|---|
| `Managers` | Авторизация, пользовательская сессия, главное меню и данные между сценами |
| `Local` | Локальная SQLite-база, модели записей и синхронизация |
| `Network` | Запросы к серверу и модели ответов API |
| `QR` | Сканирование QR-кода и кнопки навигации AR-сцены |
| `Voice` | Распознавание голосовых команд, маршрутизация и контекстные подсказки |
| `AR` | Выбор режима показа карточки, AR-размещение и управление карточками |
| `AR/Cards` | Логика карточек и итогового отчёта |

В корне папки лежат `FitToSafeArea` для формы входа и `ResponsiveMainMenu` для раскладки главного меню на разных экранах.

## Основные сценарии

### Вход и главное меню

- `LoginManager` проверяет поля и выполняет вход.
- `SessionManager` хранит данные вошедшего пользователя между сценами.
- `MainMenuManager` запускает сканирование, показывает инструкцию и открывает AR-сцену.
- `GameDataManager` передаёт последнюю строку QR в `SampleScene`.
- `QRNavigationController` обслуживает кнопки повторного сканирования и возврата в меню.

Визуальную иерархию и `Button → On Click` по возможности настраивай в Inspector. Имена объектов, используемые скриптами для поиска, следует сверять с именами в сцене.

### AR-карточки

В `Assets/App/Content/Cards` находятся три активных префаба: калькулятор, изображения шкафа и чек-лист. Внешний вид постоянных панелей и кнопок редактируется в Prefab Mode.

- `ARCardButtonHook` связывает кнопку меню с назначенным префабом.
- `ARCardModeSelector` предлагает открыть карточку поверх экрана или разместить её в AR.
- `ARCardSpawnUtility` выбирает префаб в `ObjectSpawner` и включает размещение.
- `ARCardSpawnGuard` ограничивает дубли, ориентирует новую карточку и включает XR-перетаскивание, поворот и масштабирование.
- `ARPlacedCardMarker` хранит имя типа размещённого префаба для проверки дублей.
- `ARPanelLockButton` закрепляет карточку в текущем положении и повторно разрешает её перемещение по нажатию.

Инвентаризационная карточка использует `ScrollRect` и две физические экранные кнопки прокрутки. `InventoryChecklistItemRow` управляет одной строкой «Есть / Нет». Строка клонируется из заранее оформленного шаблона в префабе: количество строк определяется данными шкафа.

| Скрипт | Назначение |
|---|---|
| `CalculatorController` | Обработка кнопок калькулятора, голосового ввода и записи действия `calc` в журнал |
| `ImageCardController` | Загрузка и переключение изображений шкафа |
| `InventoryChecklistController` | Получение списка шкафа, отметки, прокрутка и переход к отправке отчёта |
| `InventoryReportButton` | Открытие формы отчёта из действий инвентаризации |
| `InventoryReportLauncher` | Создание экземпляра готового префаба формы отчёта |
| `InventoryReportCapture` | Снимки, голосовая запись, предварительный просмотр и отправка отчёта |
| `InventoryReportPhoto` | Сохранение и кодирование фото |
| `InventoryReportVoice` | Подготовка голосовой записи для отправки |
| `InventoryReportCameraFallback` | Отображение изображения камеры на устройствах, где нужен запасной путь |

### Голосовое управление

Поток команды: `VoiceController` получает распознанную фразу → `VoiceRouter` определяет активный экран и вызывает соответствующее действие. `VoiceHelpController` показывает подсказки с командами, доступными в текущем контексте.

При добавлении кнопки сначала создай и оформи её в нужной сцене или префабе. Затем подключи событие в Inspector или добавь команду маршрутизации, если кнопка должна управляться голосом. Для выбора AR-карточки голосовой маршрут использует тот же `ARCardButtonHook`, что и нажатие.

### Локальная база и API

- `LocalDatabase` открывает SQLite в `Application.persistentDataPath` и сохраняет локальные события и ожидающие отправки отчёты.
- `LocalDatabaseModels` и `LocalActionResults` описывают данные и результаты операций на устройстве.
- `LocalClient` обрабатывает локальный вход, QR-сканирования и действия калькулятора.
- `InventoryApiClient` запрашивает данные шкафа и отправляет завершённую инвентаризацию.
- `SyncManager` отправляет накопленные события и отчёты серверу через выбранное подключение.
- `SyncButtons` обрабатывает кнопки Wi-Fi и USB главного меню.

Экспорт стартового справочника из PostgreSQL в `Assets/StreamingAssets/InventoryDatabase/inventory.db` запускается из Unity через **Tools → Database → Export PostgreSQL to SQLite**.

## Важные правила

- Сцены и префабы — источник внешнего вида и постоянной UI-иерархии.
- Скриптам оставляй обработку событий, загрузку данных и поведение, которое зависит от времени выполнения.
- Если карточка перестала использоваться, сначала проверь ссылки сцен, префабов и голосовых маршрутов; только потом удаляй её скрипты.
- Сохраняй `.meta`-файлы: по GUID Unity связывает компоненты, сцены и префабы.
