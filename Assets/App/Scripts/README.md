# Код приложения

Этот каталог содержит только код, созданный для приложения. Сцены находятся рядом в `Assets/App/Scenes`.
Инструменты для редактора находятся в `Assets/App/DatabaseTools`; мастер-копия базы хранится в `Assets/StreamingAssets/InventoryDatabase`.
Визуальные материалы и готовые AR-карточки находятся в `Assets/App/Content` — инструкция по их добавлению лежит в `Assets/App/Content/README.md`.

## Где что находится

- `Managers` — вход, главное меню, состояние пользователя и переходы между сценами.
- `Local` — SQLite, модели локальных данных, QR-разрешение и очередь синхронизации.
- `Network` — модели запросов и ответов серверного API.
- `QR` — запуск Android QR-сканера и обработка результата в Unity.
- `Voice` — распознавание речи, команды и голосовые подсказки.
- `AR/Cards` — карточки изображений и их кнопки.
- `AR/Calculator` — логика калькулятора.
- `AR/ARCardButtonHook.cs` — общий обработчик выбора калькулятора; карточка назначается через Inspector.
- `AR/ARCardSpawnUtility.cs` — единая логика выбора карточек из списка `Object Prefabs` на `ObjectSpawner`. Список не дополняется скрытно во время игры.
- `AR/Web` — WebView-карточка и оверлей.
- `UI` — общие вспомогательные компоненты интерфейса.
- `Local/SyncButton.cs` — действие кнопки синхронизации.

В `SampleScene` список `Object Prefabs` содержит ровно три карточки из `Content/Cards`: `WebCard`, `CalculatorCard`, `ProductInfoCard`. Все они наследуют одинаковые AR-компоненты перемещения и масштабирования. Случайный поворот спавна выключен; `ObjectSpawner` ориентирует карточку к камере. Интерфейсы находятся в самих Prefab и редактируются в Prefab Mode. `ARCardSpawnUtility.AddPanelDepth` отвечает за мягкую тень панели; физическая подложка не создаётся поверх Canvas.

Файлы `.meta` перемещаются вместе со скриптами: Unity использует их GUID для связей компонентов в сценах и префабах.

Сценарии использования и поток данных описаны в корневом `README.md` проекта.
